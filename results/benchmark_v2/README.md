# Benchmark V2

Ce dossier contient la deuxième campagne et sépare explicitement quatre niveaux :

- **A0** : intégration manuelle ;
- **A1** : découverte et métadonnées techniques automatiques ;
- **A2** : couche sémantique déclarative ;
- **A3** : adaptation sémantique et politique de confiance.

Deux familles de scénarios sont étudiées :

- `P00`–`P05` : structure, format, échelle et nouvelle source ;
- `S01`–`S05` : ambiguïté, définitions concurrentes, dérive et conflit
  d'identifiants.

La synthèse des scénarios sémantiques se trouve dans `semantic_benchmark/`.

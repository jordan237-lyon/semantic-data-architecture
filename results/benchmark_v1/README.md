# Benchmark V1

Ce dossier regroupe la première campagne, auparavant dispersée dans plusieurs
dossiers de `results/`. Les résultats originaux sont conservés à leur emplacement
historique ; cette arborescence en est une copie organisée et reproductible.

## Contenu

- `baseline/` : évaluation du pipeline ETL manuel ;
- `semantic/` : profilage, matching et pipeline sémantique initial ;
- `comparison/` : comparaison nominale qualité, performance et effort ;
- `perturbations/` : P01, P02 et P03 ;
- `scale/` : expérimentation P04 aux facteurs x1, x5 et x10 ;
- `new_source/` : expérimentation P05 avec la source Loyalty ;
- `final/` : synthèse finale de la campagne V1.

V1 compare deux familles : **baseline manuelle** et **pipeline sémantique**.
Elle ne contient pas encore la décomposition A0–A3 ni les scénarios S01–S05.
